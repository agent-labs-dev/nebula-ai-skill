# nebula-ai 0.1.20

===== nebula-ai
Usage: nebula-ai [options] [command]

CLI/TUI for the nebula.gg AI task orchestration platform

Options:
  -V, --version             output the version number
  --api-url <url>           Override API URL
  --json                    Output raw JSON
  -v, --verbose             Verbose output (alias for --log-level=debug)
  --log-level <level>       Log verbosity (error|warn|info|debug|trace)
  --workspace <id-or-slug>  Workspace to use for this session (overrides stored
                            preference)
  --no-color                Disable colors
  -h, --help                display help for command

Commands:
  login                     Authenticate with nebula via the device-flow pairing
  logout                    Clear stored credentials
  status                    Show CLI status overview
  usage [options]           Show workspace token usage and cost
  chat [options] [message]  Send a message to an agent DM and print the reply
  call                      Voice calls
  open <link>               Resolve a nebula://open link (--json prints the
                            entity)
  channels|spaces           View and work inside Channels
  tasks                     Manage Tasks
  agents                    Manage agents
  user                      View or update user profile and account settings
  profile                   View or update your user profile
  local-device              Manage computer use and the local device daemon
  install [options]         Set up computer use (alias of `local-device enable`)
  uninstall [options]       Turn off computer use, stop the daemon, and remove
                            this device
  update [options]          Check for a newer CLI version and install it
  completion <shell>        Generate a shell completion script (bash|zsh|fish)
  capabilities              Probe and print this host's capability snapshot
  logs                      Inspect Nebula log files on disk
  models                    List and manage the models this workspace can use
  workspace                 Manage workspaces
  integrations              Connect and manage workspace integrations
  help [command]            display help for command

===== nebula-ai chat
Usage: nebula-ai chat [options] [message]

Send a message to an agent DM and print the reply

Arguments:
  message                 Message to send (omit when using --resume)

Options:
  -a, --agent <name>      Agent name, slug, or ID (defaults to first active
                          agent)
  -t, --task <id>         Send to a specific Task instead of an agent DM
  --context <glob>        Attach files matching a glob pattern (repeatable, e.g.
                          --context 'src/**/*.ts') (default: [])
  -r, --resume <task-id>  Boot the TUI directly into an existing Task (no
                          message needed)
  --no-stream             Wait quietly, without the running tool commentary
  -h, --help              display help for command

===== nebula-ai call

Voice calls

Options:
  -h, --help             display help for command

Commands:

  end <task>             End the live Call on a Task for everyone
  join [options] <task>  Join a call (TUI; --headless for engine-only; --json)
