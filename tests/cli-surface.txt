# nebula-ai 0.1.33

===== nebula-ai
Usage: nebula-ai [options] [command]

CLI/TUI for the nebula.gg AI task orchestration platform

Options:
  -V, --version             output the version number
  --api-url <url>           Override API URL
  --json                    Output raw JSON
  -v, --verbose             Verbose output (alias for --log-level=debug)
  --log-level <level>       Log verbosity (error|warn|info|debug|trace)
  --workspace <id-or-slug>  Workspace to use for this session (overrides stored
                            preference)
  --no-color                Disable colors
  -h, --help                display help for command

Commands:
  login                     Authenticate with nebula via the device-flow pairing
  logout [options]          Sign out the current account (--all signs out every
                            account)
  account|accounts          Manage signed-in accounts
  status                    Show CLI status overview
  credits [options]         Show this workspace's credit balances and recent
                            additions
  chat [options] [message]  Send a message to an agent DM and print the reply
  call                      Voice calls
  open <link>               Resolve a nebula://open link (--json prints the
                            entity)
  channels                  View and work inside Channels
  tasks                     Tasks: create them, follow them, and organise them
  agents                    Agents: list, read, create and configure them
  messages                  Messages: send, list, replies, threads, edit,
                            delete, react and share
  members                   The people in this workspace
  inbox                     Your inbox: the threads addressed to you, and Done
  approvals                 Actions agents are waiting on you to approve or deny
  jobs                      Jobs: work that runs on a schedule
  miniapps                  Miniapps: list, create and delete them
  skills                    Skills: list, save and delete workspace and personal
                            skills
  local-device              Manage computer use and the local device daemon
  install [options]         Set up computer use (alias of `local-device enable`)
  uninstall [options]       Turn off computer use, stop the daemon, and remove
                            this device
  update [options]          Check for a newer CLI version and install it
  completion <shell>        Generate a shell completion script (bash|zsh|fish)
  capabilities              Probe and print this host's capability snapshot
  logs                      Inspect Nebula log files on disk
  workspace                 Manage workspaces
  acp [options]             Run an Agent Client Protocol server over stdio, for
                            an editor that speaks ACP
  help [command]            display help for command

===== nebula-ai chat
Usage: nebula-ai chat [options] [message]

Send a message to an agent DM and print the reply

Arguments:
  message                 Message to send (omit when using --resume)

Options:
  -a, --agent <name>      Agent name, slug, or ID (defaults to first active
                          agent)
  -t, --task <id>         Send to a specific Task instead of an agent DM
  --context <glob>        Attach files matching a glob pattern (repeatable, e.g.
                          --context 'src/**/*.ts') (default: [])
  -r, --resume <task-id>  Boot the TUI directly into an existing Task (no
                          message needed)
  --new                   Start a new chat with the agent instead of its DM
  --no-stream             Wait quietly, without the running tool commentary
  -h, --help              display help for command

Close a thread for everyone in it; a reply or a new Task reopens it

Arguments:
  root-id     The ID of the message that started the thread

Options:
  --stop      Stop the thread's running Tasks first
  -h, --help  display help for command

===== nebula-ai inbox
Usage: nebula-ai inbox [options] [command]

Your inbox: the threads addressed to you, and Done

Options:
  -h, --help         display help for command

Commands:
  list [options]     List the threads in your inbox (! = needs you, * = unread),
                     or with --done the ones you marked Done
  done <root-id>     Mark a thread Done: it leaves your inbox until something
                     new arrives
  restore <root-id>  Bring a thread you marked Done back to the top of your
                     inbox
  help [command]     display help for command

===== nebula-ai inbox list
Usage: nebula-ai inbox list [options]

List the threads in your inbox (! = needs you, * = unread), or with --done the
ones you marked Done

Options:
  --done          List the threads you marked Done instead
  --sort <order>  created (arrival, default) or updated (latest first); not with
                  --done
  --limit <n>     Max threads (up to 500) (default: "50")
  -h, --help      display help for command
