# nebula-ai-skill

The public Agent Skill that teaches agents to use Nebula through its MCP server or the `nebula-ai` CLI (`nebula-ai/SKILL.md` plus `nebula-ai/references/`). It is verified against exactly one CLI version, pinned in `nebula-ai/cli-version`.

## Gate

```sh
tools/gate             # check_skill.py (commands, options, versions, public text) and shellcheck
tools/gate --changed   # shellchecks only the shell scripts changed against origin/main
```

CI also validates the skill format (`uvx --from skills-ref==0.1.1 agentskills validate ./nebula-ai`) and `tools/snapshot-cli.sh --check`, which needs the network.

## Invariants

- Document only released, publicly documented CLI and MCP behaviour. Every `nebula-ai` command in the docs must exist, with valid options, in `tests/cli-surface.txt`.
- `tests/cli-surface.txt` is generated by `tools/snapshot-cli.sh`; never edit it by hand.
- Bumping the CLI version touches `cli-version`, the snapshot, `SKILL.md` frontmatter (`compatibility`, `metadata.cli-version`, `metadata.version`), the references, the README table and `CHANGELOG.md`. Follow "Updating the supported CLI version" in [CONTRIBUTING.md](CONTRIBUTING.md).
- The repo is public: no local paths, loopback hosts, internal hosts, real IDs, accounts or emails. Use placeholders such as `<agent-handle>`.
- The CLI path calls the CLI directly; if a task needs a helper script, fix the CLI instead.
