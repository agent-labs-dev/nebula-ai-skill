# nebula-ai 0.1.9

===== nebula-ai
Usage: nebula-ai [options] [command]

CLI/TUI for the nebula.gg AI task orchestration platform

Options:
  -V, --version             output the version number
  --api-url <url>           Override API URL
  --json                    Output raw JSON
  -v, --verbose             Verbose output (alias for --log-level=debug)
  --log-level <level>       Log verbosity (error|warn|info|debug|trace)
  --workspace <id-or-slug>  Workspace to use for this session (overrides stored
                            preference)
  --no-color                Disable colors
  -h, --help                display help for command

Commands:
  login                     Authenticate with nebula via the device-flow pairing
  logout                    Clear stored credentials
  status                    Show CLI status overview
  usage [options]           Show workspace token usage and cost
  chat [options] [message]  Send a message to an agent DM and stream the
                            response
  call                      Voice calls
  channels                  Manage channels (threads)
  agents                    Manage agents
  user                      View or update user profile and account settings
  profile                   View or update your user profile
  local-device              Manage computer control and the local device daemon
  install [options]         Set up computer control (alias of `local-device
                            enable`)
  uninstall [options]       Turn off computer control, stop the daemon, and
                            remove this device
  update [options]          Check for a newer CLI version and install it
  completion <shell>        Generate a shell completion script (bash|zsh|fish)
  capabilities              Probe and print this host's capability snapshot
  logs                      Inspect Nebula log files on disk
  models                    List and manage the models this workspace can use
  workspace                 Manage workspaces
  integrations              Connect and manage workspace integrations
  help [command]            display help for command

===== nebula-ai chat
Usage: nebula-ai chat [options] [message]

Send a message to an agent DM and stream the response

Arguments:
  message                    Message to send (omit when using --resume)

Options:
  -a, --agent <name>         Agent name, slug, or ID (defaults to first active
                             agent)
  -c, --channel <id>         Send to a specific channel ID instead of agent DM
  --context <glob>           Attach files matching a glob pattern (repeatable,
                             e.g. --context 'src/**/*.ts') (default: [])
  -r, --resume <channel-id>  Boot the TUI directly into an existing channel (no
                             message needed)
  --no-stream                Wait for full response instead of streaming
  -h, --help                 display help for command

===== nebula-ai install
Usage: nebula-ai install [options]

Set up computer control (alias of `local-device enable`)

Options:
  --source <name>          Metadata source for this install (default: "cli")
  --primary-folder <path>  Override the working folder instead of using the
                           current directory
  -h, --help               display help for command

===== nebula-ai models custom add
Usage: nebula-ai models custom add [options] <name>

Add a custom model

Options:
  --alias <model-id>    Create a routing alias to a catalog model
  --base-url <url>      OpenAI-compatible endpoint
  --model-id <id>       Model id to send upstream
  --auth <value>        Authorization header value
  --device <device-id>  Lock this model to a device
  --share               Make it visible to the whole workspace
  -h, --help            display help for command
